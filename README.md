# Customer Purchase Prediction

## Objective
To predict whether a customer will purchase a product based on their age and salary.

## Dataset
The dataset contains:
- Age
- EstimatedSalary
- Purchased

## Machine Learning
I used:
- Logistic Regression
- SVM

## Steps
1. Data Cleaning
2. Exploratory Data Analysis
3. Train-Test Split
4. Feature Scaling
5. Model Training
6. Model Evaluation
7. Model Comparison

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score

## Result
The model achieved good performance in predicting customer purchases.
